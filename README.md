# Central Financeira

Gestão financeira pessoal: contas a pagar, contas e cartões, lançamentos, dívidas e análise.

- Página única (`index.html`), publicada pelo GitHub Pages.
- Dados no Supabase, em tabelas `fin_*` protegidas por login e por regras de acesso por usuário (RLS).
- O código é público, mas não contém nenhum dado: sem login, o banco não devolve nada.
